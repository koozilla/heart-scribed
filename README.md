# Heart Scribed

A beautiful Bible verse memorization mobile app to help you hide God's Word in your heart.

## Static Promo Page

The `index.html` file is a simple static promotional page that you can open directly in your browser - no installation needed!

Simply open `index.html` in your browser to view the promo page.

## Features

- Daily Bible verses with beautiful backgrounds
- Save favorite verses
- Search functionality
- Memorization mode
- Beautiful, modern dark UI
- Responsive design

## Deployment

See `DEPLOY.md` for instructions on deploying this static promo page to Vercel.
