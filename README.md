# Heart Scribed

A beautiful Bible verse memorization mobile app to help you hide God's Word in your heart.

## Static Promo Page

The `index.html` file is a simple static promotional page that you can open directly in your browser - no installation needed!

## Next.js App (Optional)

If you want to develop a full Next.js web app, you can use the files in the `app/` directory.

### Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features

- Daily Bible verses with beautiful backgrounds
- Save favorite verses
- Search functionality
- Memorization mode
- Beautiful, modern dark UI
- Responsive design

## Tech Stack

- Next.js 14 (App Router) - for web app
- React 18
- TypeScript
- Tailwind CSS
- Static HTML - for promo page
