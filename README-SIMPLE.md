# Heart Scribed - Promo Page

This is a simple static promotional page for Heart Scribed. No installation or build process needed!

## How to View

Simply open `index.html` in your web browser:

1. **Double-click** `index.html` in Finder, OR
2. **Right-click** `index.html` → "Open With" → Your browser, OR
3. **Drag and drop** `index.html` into your browser window

## Adding Your Background Image

To use the beautiful verse background image from your screenshots:

1. Save your image as `verse-background.jpg`
2. Place it in the same folder as `index.html`
3. Refresh the page

If the image doesn't exist, a beautiful gradient will be shown as a fallback.

## Customization

The page is a single HTML file with inline Tailwind CSS (via CDN). You can edit `index.html` directly to customize:
- Colors
- Text content
- Layout
- Images

No build tools or npm required!
